- When the lookup behind a gate's `no_open_blockers` criterion fails (the index cannot be read, a storage error, a timeout), `sw_check_ready`, `sw_transition`, `sw_refine`, `sw_review` approving and the matching `pyrite sw` commands now answer the lookup's own error, with its own code and `retryable`, instead of a not-retryable `VALIDATION_FAILED` that told you to fix `board.yaml`. This holds when the KB has no `board.yaml` too. The call still changes nothing and the criterion is never recorded as passed (#1585).
