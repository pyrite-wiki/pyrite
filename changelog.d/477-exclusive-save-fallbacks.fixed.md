Exclusive entry creation now cleans a failed claim, keeps post-link cleanup errors distinct from collisions, and falls back only when an atomic filesystem operation is unsupported. Behaviour change: when the exclusive (O_EXCL) create itself fails, the save now raises instead of falling back to a plain replace, so a filesystem that rejects O_EXCL (some FUSE mounts answer EINVAL or EPERM) fails every exclusive create rather than risking an overwrite.
