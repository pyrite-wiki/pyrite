- **CI now runs the Postgres backend tests (#1766).** A dedicated `postgres` job in `ci.yml` starts a Postgres service container, sets `PYRITE_TEST_PG_URL`, and runs `tests/backends/` (the Postgres test modules and the backend conformance suite) on Python 3.12. A Postgres schema or migration change (`ensure_schema`, mark-for-reread) is now exercised by CI instead of being judged by reading; previously those tests were deselected with the experimental surface in the gating matrix and tolerated by the experimental job's ratchet.
