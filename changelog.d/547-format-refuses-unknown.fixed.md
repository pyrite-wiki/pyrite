- **Every `--format` that names an output format now refuses a value outside the command's accepted list, before the command acts (#547).** `pyrite list`, `recent`, `orient`, `init`, `kb health|validate|schema ...`, `index health|stats`, `qa ...`, `extension list`, `auth status|whoami`, `ids ...`, `repo list`, `collections ...`, `timeline`, `ci`, all `sw` commands and `pyrite-read list|tags|timeline|get|backlinks` exit 2 with `unknown format 'bogus'; choose one of: ...` before they act. Before, most ended in a traceback (and `pyrite init --format bogus` created and registered the KB first, then crashed), the rest ignored the value and printed rich text or JSON anyway. A command that renders only `json` and `rich` (`sw`, `qa gaps|coverage|checkers|check-urls`) or `text` and `json` (`ci`, `ids`) now says so instead of accepting `yaml` or `csv` and printing something else. The file-format options of `import` and `export` are unchanged.
