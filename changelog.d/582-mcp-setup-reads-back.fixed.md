- `pyrite mcp-setup` registers the Pyrite MCP server where each client reads it. Before, it wrote `~/.claude/claude_desktop_config.json`, which no client reads. Claude Code gets it through `claude mcp add -s user` (or `./.mcp.json` with `--project`), and Claude Desktop in its own `claude_desktop_config.json` (macOS `~/Library/Application Support/Claude/`, Windows `%APPDATA%\Claude\`). With no `--client`, every client found is configured and named. The entry runs this install's `pyrite` by absolute path with an explicit `--tier`, default `write`. Before, it registered `pyrite-admin mcp`, which served the admin tier, and fell back to a bare `python` when `pyrite-admin` was not on `PATH`. The command checks that the server starts before writing. With no client found it exits 1 and prints the entry to paste. Invalid JSON in an existing config is a clear error that leaves the file untouched, writes are atomic, and a re-run leaves one entry. (#582)
