- A declared-boolean MCP argument sent as the string `"false"` no longer reads as true. The dispatcher normalises every declared-boolean argument once, before the tool runs: JSON `true`/`false` pass, the strings `"true"`/`"false"` (stripped, any case) become a bool, `null` is treated as absent so the argument's default applies, and any other value (`0`, `1`, `"yes"`, a list) answers `INVALID_PARAMETER` naming the argument. Plugin tools are covered by the same dispatcher rule (#1744).
