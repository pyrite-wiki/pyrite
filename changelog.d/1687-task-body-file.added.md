`pyrite task create` and `pyrite task update` take `--body-file <path>` (`-` reads stdin) and `--stdin`, and `task update` takes `--body`. Two body sources, or a `--body-file` that is missing or a directory, are usage errors (exit 2). A file or stdin text that opens with frontmatter is refused (`VALIDATION_FAILED`) with a pointer to `pyrite create -t task --body-file`. (#1687)
