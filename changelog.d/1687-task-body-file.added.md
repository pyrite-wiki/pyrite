`pyrite task create` and `pyrite task update` take `--body-file <path>` (`-` reads stdin) and `--stdin`, and `task update` takes `--body`. Two body sources are a usage error (exit 2); a `--body-file` that is missing or a directory is refused as every input file is (exit 1, `NOT_FOUND` / `VALIDATION_FAILED`). A file or stdin text that opens with frontmatter is refused (`VALIDATION_FAILED`) with a pointer to `pyrite create -t task --body-file`. (#1687)
