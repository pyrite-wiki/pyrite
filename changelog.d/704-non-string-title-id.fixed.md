- **Files with a numeric or boolean `title:` are indexed instead of silently skipped (#704).** A `title:` that YAML reads as a number or boolean (`title: 1e3`, `title: 2024`, `title: true`) used to raise during id derivation, so the file was absent from the index and `ids missing` listed it as skipped. The title is now stringified before slugging (`1e3` → `1000-0`, `2024` → `2024`, `true` → `true`), and `ids missing` reports such files with the id they now have.
