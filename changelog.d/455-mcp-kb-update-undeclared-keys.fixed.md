- **MCP `kb_update` stores keys the entry type does not declare**, the way `pyrite update -f` and REST `PATCH` do (#455); it used to drop them and report `updated: true`. Keys a `kb_get` result carries that no update writes (the id, path, timestamps, managed fields, index columns, and `null`s for fields the entry does not use) are not written and are listed in the result's new `ignored` field.
