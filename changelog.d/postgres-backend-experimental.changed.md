The Postgres backend is marked experimental in 0.25.x: it has no migration for columns added after alembic revision 006, so an existing Postgres database may not upgrade between releases ([#718](https://github.com/pyrite-wiki/pyrite/issues/718)). No 0.25.x code path builds the Postgres backend, and nothing reads `search_backend` or `database_url` yet, so the notice and its variable matter only to code that constructs the backend directly. Building it now says so once per process, on stderr and in the server log, never on stdout, and the notice can never stop the backend being constructed; set `PYRITE_POSTGRES_EXPERIMENTAL_ACK=1` to silence it. SQLite users see nothing new.
