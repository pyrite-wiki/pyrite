The Postgres backend is marked experimental in 0.25.x: it has no migration for columns added after alembic revision 006, so an existing Postgres database may not upgrade between releases ([#718](https://github.com/pyrite-wiki/pyrite/issues/718)). Building the backend now says so once per process, on stderr and in the server log, never on stdout; set `PYRITE_POSTGRES_EXPERIMENTAL_ACK=1` to silence it. SQLite users see nothing new.
