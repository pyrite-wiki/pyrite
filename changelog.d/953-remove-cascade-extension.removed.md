- **The cascade extension is gone (#953).** `extensions/cascade/` (the `cascade-research`, `cascade-timeline` and `cascade-solidarity` KB types; the `actor`, `cascade_org`, `cascade_event`, `timeline_event`, `theme`, `victim`, `statistic`, `mechanism`, `scene` and `solidarity_event` types; the `pyrite cascade` commands; the `cascade_*` and `solidarity_*` MCP tools) is deleted. The cascade public site moved to Hugo. A KB still registered with one of those KB types is still a KB: its files read and write as generic entries, and `pyrite orient -k <kb>` (`notices`) and `pyrite index health` (`removed_extensions`) say so in one sentence instead of leaving the types silently undeclared. For investigative types, install journalism-investigation and set `kb_type: journalism-investigation`; the `member_of`/`has_member` and `funded_by`/`funds` relations that journalism-investigation's connection hook writes moved into that extension.
