Filtered semantic searches on SQLite now apply caller filters (KB, type, tags, dates, `fips`, `state`, status) inside sqlite-vec's KNN query, so unrelated nearby entries no longer use the candidate budget before a selective filter is applied; archived entries that fill the nearest slots no longer empty an unfiltered search either (#194). More than 4,096 matching rows still returns at most 4,096 (sqlite-vec's ceiling on `k`), and a caller scoped by readable KBs without naming a `kb_name` can still come back short, because that check runs after the KNN.
