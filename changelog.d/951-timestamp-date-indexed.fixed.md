- **An entry whose `date:` is a full YAML timestamp is indexed (#951).** A typed entry (an ADR, an event) with `date: 2025-06-01T00:00:00+00:00` was skipped by `index build` and `index sync` with only a log warning, because the loader's timestamp type could not be bound to the index; the entry was invisible to `get`, search and lists. Every temporal column (`date`, `start_date`, `end_date`, `due_date`, `assigned_at`) now stores a date or timestamp as one text form, `2025-06-01` or `2025-06-01 00:00:00+00:00`, whatever the file's spelling, and a read of the file returns the same text.
