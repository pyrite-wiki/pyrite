- **An entry carrying a YAML timestamp is indexed (#951).** An entry with `date: 2025-06-01T00:00:00+00:00` (an ADR, an event, a task's `start_date`, `end_date`, `due_date` or `assigned_at`), a source whose `date` is a timestamp, or a tag that reads as one, was skipped by `index build` and `index sync` with only a log warning, because the loader's timestamp type could not be bound to the index; the entry was invisible to `get`, search and lists. Every such value is now bound as text in one form, `2025-06-01` or `2025-06-01 00:00:00+00:00`, whatever the file's spelling. A read of the entry still reports the file's own spelling (`2025-06-01T00:00:00+00:00` for a file spelled with `T`), not the index's.
