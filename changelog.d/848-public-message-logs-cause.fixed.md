A refused CLI command whose error carries a fixed public message (`StorageError`, `ConfigError`, `PluginError` and the config and branding refusals) now writes the real cause to stderr at the default log level, as REST and MCP already did on their server logs. stdout and every response body are unchanged. One helper, `pyrite.exceptions.public_text`, now decides what a response shows and logs the cause, and a test fails when any other module reads `.public_message` (#848).
