- `pyrite-admin mcp` now defaults to the `write` tier, like `pyrite mcp` (ADR-0006), and rejects an unknown tier with `INVALID_TIER`. A hand-written MCP config that runs `pyrite-admin mcp` with no `--tier` and relied on the admin tools (`kb_push`, `kb_registry_*`, `kb_commit`, ...) must add `"--tier", "admin"` to its args. `pyrite-admin mcp-setup` is removed: it ignored `--tier` and wrote three servers (`pyrite-read`, `pyrite-write`, `pyrite-admin`) to a file no client reads. Use `pyrite mcp-setup --tier <tier>`, which removes that stale trio from any config file it writes. (#582)
