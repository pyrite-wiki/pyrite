- **`soupsieve` is locked at 4.1.1 on Python 3.11.5 and newer, which closes two upstream advisories there (#1536).** The advisories are GHSA-mmhr-3c5m-f64f (CVE-2026-126190, polynomial-time denial of service in the descendant combinator; affects `soupsieve` before 4.0.0) and GHSA-6655-6qjp-jx7x (CVE-2026-126191, exponential ReDoS in selector compilation; affects 2.10 and earlier, fixed in 3.0.2). `requires-python` stays `>=3.11`, and on Python 3.11.0 to 3.11.4 `uv.lock` still resolves `soupsieve` 2.10, which both advisories affect, because no patched release supports those Pythons. `uv.lock` governs `uv sync` only: an environment built before 0.26.4 (or by `pip install -e ".[all]"`) keeps the `soupsieve` it has. **What to do:** on Python 3.11.5 or newer, upgrade `soupsieve` in an existing environment to 4.0.0 or later (`pip install -U "soupsieve>=4.0.0"`, or `uv sync` in a clone); on Python 3.11.0 to 3.11.4, move to Python 3.11.5 or newer to get the fix.
