- **The built-in public site is gone (#953).** `/site`, `/site/search`, `/site/sitemap.xml`, `/viewer`, the live `/sitemap.xml` and `/robots.txt`, `POST /api/site/render`, the `site_cache` field of `POST /api/index/sync?wait=true`, the web app's "Render Site" button and `SiteCacheService` are removed, with their templates and the `jinja2` dependency. Publishing is an export: `pyrite export site` (Quartz), or the web app behind `pyrite serve` for readers. A `site-cache/` directory left under `PYRITE_DATA_DIR` by an older version is inert and can be deleted. `PYRITE_SITE_CSP_EXTRA` / `settings.site_csp_extra` stays: it extends the web app's Content-Security-Policy, which it already did.
