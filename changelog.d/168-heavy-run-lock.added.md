One heavy test run at a time per machine (#168): `scripts/test-affected --run` (and so the pre-push hook), `scripts/verify-red.sh` and the new `scripts/e2e.sh` (which `npm run test:e2e` now calls) take one lock per user, `~/.cache/pyrite/heavy.lock`, shared by every worktree. A second run waits in arrival order, naming the holder, instead of running beside it; a killed holder releases it; `PYRITE_SUITE_LOCK_SKIP=1` skips it and CI takes none. Local Playwright runs use 2 workers (`PW_WORKERS`), and `scripts/machine_ok.sh` gives the conductor's health step a load/memory check with an exit code.
