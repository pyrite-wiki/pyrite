One heavy test run at a time per machine (#168): `scripts/test-affected --run` (and so the pre-push hook), `scripts/verify-red.sh` and the new `scripts/e2e.sh` (which `npm run test:e2e` now calls) take one lock per user, `~/.cache/pyrite/heavy.lock`, shared by every worktree. A second run waits in arrival order, naming the holder, instead of running beside it; the lock is let go only when the run's command has ended, and a killed holder never leaves a stale lock (the next run waits for the command it left running, then starts); `PYRITE_SUITE_LOCK_SKIP=1` skips it and CI takes none. `PW_WORKERS` sets local Playwright workers, and `scripts/machine_ok.sh` gives the conductor's health step a load/memory check with an exit code.
