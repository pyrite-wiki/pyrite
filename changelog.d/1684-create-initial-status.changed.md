Creating an entry of a type with a workflow or state machine (such as `task`) in any status other than its initial state (`open`) is now refused on every create surface (`pyrite create`, body-file frontmatter, MCP `kb_create`, and REST). The refusal message directs callers to `task claim` or `task update --status`. Ingest paths (`add`, `import`, and `sync`) are exempt and record the file's status as given.
