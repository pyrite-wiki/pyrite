`atomic_write_text` takes `expect=` (the file's expected bytes, a sha256 hex digest, or `ABSENT`) and, under a new momentary stripe lock (`pyrite.utils.file_lock`), writes nothing and raises `FileChanged` when the file differs. The lock directory is per user in every environment. Two OS users exclude each other only when `PYRITE_LOCK_DIR` names one absolute, root-owned sticky directory (mode 1777); a directory owned by an ordinary user is refused for everyone else, and a symlink, a foreign owner or a directory others can write without sticky is refused. Not supported on Windows. Nothing calls it yet (ADR-0042 decision 10, B6 P2).
