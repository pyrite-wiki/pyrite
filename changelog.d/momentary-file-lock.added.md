`atomic_write_text` takes `expect=` (the file's expected bytes, a sha256 hex digest, or `ABSENT`) and, under a new momentary stripe lock (`pyrite.utils.file_lock`), writes nothing and raises `FileChanged` when the file differs. The lock directory is per user by default; two OS users exclude each other only when `PYRITE_LOCK_DIR` points both at one directory that is owned by one of them or root and is not writable by others unless sticky.
