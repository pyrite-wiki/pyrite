- A symbolic link inside a KB to another entry file of the same KB (`sub/alias.md -> ../a.md`, relative or absolute, in any folder, or a chain of links) is now an alias of that entry: it is indexed once, at the real file, and `pyrite index sync` and `pyrite index health` list it under a new `aliases` key (`{kb, path, target}`) instead of reporting a duplicate id. Before, sync said "Duplicate ids: 1", the first path by name could be indexed in place of the real file, and a lookup by id could return the link. Pyrite never rewrites or removes the link. A link to a file the walk skips, a link that leaves the KB, a dangling link and a hard link are read as before. (#1262)
