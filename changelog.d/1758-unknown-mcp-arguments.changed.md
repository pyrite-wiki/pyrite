- MCP no longer drops an argument key a tool does not declare without saying so. A write tool refuses the call before writing, with `VALIDATION_FAILED`. The refusal names each unknown key, suggests a near miss (`task_create` `due` -> `due_date`) and lists the accepted keys. A read tool runs the call and lists the undeclared keys in the result's `ignored_arguments`. KB arguments, which the dispatcher checks on every tool, are never unknown. `kb_create` and `kb_update` still take a type's own fields at the top level, and nested maps (`metadata`, `fields`) are unchanged (#1758).
