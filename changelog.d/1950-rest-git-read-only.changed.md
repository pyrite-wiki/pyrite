- **REST git operations now answer `403` `KB_READ_ONLY` (`retryable: false`) through the central handler for a read-only KB (#1950).** `POST /api/kbs/{kb}/commit`, `POST /api/kbs/{kb}/push`, and `POST /api/kbs/{kb}/publish` delegate `KBReadOnlyError` to the central handler instead of raising route-local HTTPExceptions or reporting `PUBLISH_FAILED`. Work originated in #1945 by @DhyaanKanoja11 and #1949 by @markramm.
