- **`PUT /api/kbs/{name}` no longer erases a KB's metadata field you did not send (#521).** Sending only `description` used to fail with a database error, and sending only `kb_type` wiped the description. An omitted field is now left unchanged, `description: null` clears the description, and `kb_type: null` is refused with `VALIDATION_FAILED` because a KB always has a type.
