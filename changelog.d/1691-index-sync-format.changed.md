- `pyrite index sync` honours `PYRITE_FORMAT` and takes `--format` (`json`, `yaml`, `rich`) like every command on the outcome contract: with `PYRITE_FORMAT=json` or `--format json` it prints the sync result, and any refusal, as JSON with an `outcome` key, where it printed text before. With no format asked for, it answers as before: its text, counts, refusals and exit codes are unchanged (#1691).
