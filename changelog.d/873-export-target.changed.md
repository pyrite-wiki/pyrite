- **`pyrite export collection` and `pyrite export site` name the destination with `--target` (#873).** `--format` is the shared output-format option of the outcome contract (ADR-0046), so the two meanings could not share a spelling. `--target notebooklm` and `--target quartz` behave exactly as `--format` did; the default is unchanged. Passing `--target` and `--format` with different values is a usage error (exit 2).
 An unknown target (for either command, under `--target` or `--format`) is now a usage error, exit 2, naming the valid values, before anything is written: `export collection` used to ignore the value and write NotebookLM files, and `export site` exited 1 with "Unknown site format".
