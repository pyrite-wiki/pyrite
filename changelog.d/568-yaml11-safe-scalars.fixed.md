- **Frontmatter stays a string for every YAML reader, not only Pyrite's own** (#568). `pyrite update -f decision=yes` used to write `decision: yes` bare; a reader implementing YAML 1.1 (PyYAML's `safe_load`, the most common Python YAML library) resolves that to the boolean `true`, not the string `"yes"` Pyrite itself reads it as. Any string value Pyrite writes that a YAML 1.1 reader would resolve to something other than a string -- `yes`/`no`/`on`/`off` in any case, `true`/`false` in any case, `~`/`null`/empty, and 1.1-only numbers such as sexagesimal `1:30`, `0777`, `0o17`, `1_000` -- is now quoted, at any nesting depth and inside list items. A real boolean or number stays unquoted, and a value already quoted in the file keeps its own quoting style.
