- A cancelled child no longer counts toward its parent's completion. A task with children and a non-terminal own status is complete by its children only when at least one child is `done` and every other child is `done` or `cancelled`. A parent whose remaining children are all cancelled (one cancelled child included) now keeps its own status: it stays in `task list --status open`, every status filter matches it as open, and it can be claimed. A grandparent follows the same rule. No file is rewritten. A KB that cancelled a parent's last child on purpose, to close the parent, now closes the parent itself: `pyrite task update <parent> -k <kb> --status cancelled`, or claim it and walk it to `done`. The `open` to `done` shortcut stays for a parent complete by its children, so it no longer applies to a parent whose children are all cancelled (#1683).
