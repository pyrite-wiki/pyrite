`--fields` is now honoured in CSV, Markdown and Rich output, not only JSON and YAML: `search`, `recent`, `list-entries`, `batch-read` and `get`, and REST search and `GET /entries/{id}` with `Accept: text/csv` or `text/markdown`, print the identity columns `id` and `kb_name` first and then the requested fields in the order given, with a column for a field no record has. A Rich table shows the whole `id` and every header; in a terminal too narrow for that, each record prints as `field: value` lines instead of a table with `…`-cut cells.
