- **Sending a `kb_get` result back to MCP `kb_update` changes only what you changed** (#561). A field still at the value the read returned is set aside and listed in `ignored`, so `importance: high` is no longer rewritten as `5` and a task no longer grows `importance: 5` and `priority: '5'`. Updating an event's `status` (echoed or set) no longer fails with `'str' object has no attribute 'value'`; an unknown status is refused with the allowed values. `tags: Foo` (and `aliases: Foo`) is read as one tag instead of its characters, and a bare URL in `sources:` is read as the source's URL.
