## Branches, Hooks and Pull Requests

For branches, worktrees, pre-commit and pre-push hooks, and pull requests, see [CONTRIBUTING.md](../../CONTRIBUTING.md), "Branches, hooks and pull requests".

## Commit Messages

Follow conventional commits: `feat`, `fix`, `docs`, `test`, `refactor`, `chore`.
Keep the subject line concise, and use the body for details and issue links (`Fixes #...`).
